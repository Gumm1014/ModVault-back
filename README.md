# ModVault - Back
API REST de ModVault, una plataforma web de mods de videojuegos. Trayectoria Pedagógica Interdisciplinaria (TPI) del Colegio Técnico Provincial Olga B. de Arko.

Repositorio del front: https://github.com/Gumm1014/ModVault-front

## Tecnologías
- Node.js y Express
- MySQL (mysql2)
- express-fileupload para la subida de archivos
- bcrypt para el hasheo de contraseñas
- jsonwebtoken para la autenticación con token

## Roles
- **Visitante:** sin cuenta, solo consulta.
- **Usuario común:** todo el que se registra.
- **Administrador:** se asigna manualmente en la base de datos.
